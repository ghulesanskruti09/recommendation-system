# Recommendation System

## Description

This project implements a simple content-based movie recommendation system
using Python.

The system recommends movies based on the similarity between their genres.

## Recommendation Technique

Content-Based Filtering

## Technologies Used

- Python
- Sets and Lists
- Basic Recommendation Logic

## Features

- Displays available movies
- Takes the user's favorite movie as input
- Compares movie genres
- Recommends similar movies

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:
